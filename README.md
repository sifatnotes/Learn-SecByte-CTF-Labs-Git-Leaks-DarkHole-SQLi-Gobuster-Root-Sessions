## Learning Path

A practical learning sequence is:

1. Begin with **Commit Trail** to understand the Git-history theme.
2. Explore **Git Leak Hunt**, **GitShadow**, and **GitShadows** scenarios.
3. Continue with the **GitGhost** and **GitVault** repository-focused labs.
4. Explore **Gobuster Ghost Paths** for path-discovery concepts.
5. Study **DarkHole Panel Hunt** for web application discovery.
6. Continue with **Hidden Paths Git SQLi Root** for the SQL injection-focused scenario.
7. Finish with **Git to Root Session Hijack Lab** for the session-hijacking/root-focused exercise.

Difficulty ratings are not specified by the supplied URLs, so this repository does not assign difficulty levels.

## How to Use the Labs

1. Choose a lab from the direct index.
2. Open the corresponding Learn SecByte resource.
3. Follow the lab's own setup and instructions.
4. Work exclusively against the authorized CTF/lab target.
5. Record the vulnerabilities, security concepts, and defensive lessons encountered.
6. Use the exercises to strengthen practical cybersecurity and penetration-testing knowledge.
7. Never apply testing techniques to systems without explicit authorization.
